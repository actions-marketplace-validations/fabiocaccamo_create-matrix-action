# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v7](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v7) - 2026-05-08
-   Fix `ReDoS` vulnerability in regex pattern. (#16)
-   Pin actions to SHA and restrict permissions. (#15)
-   Add `OpenSSF Scorecard` workflow and badge. (#15)
-   Bump `github/codeql-action` in the github-actions group. (#17)

## [v6](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v6) - 2025-12-11
-   Convert from Docker to composite action for faster execution.
-   Run tests on full matrix.
-   Add `Python 3.14` support.
-   Add `Django 6.0` support.

## [v5](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v5) - 2025-01-18
-   Add tests and run them in GitHub CI.
-   Add `pyproject.toml`.

## [v4](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v4) - 2024-02-05
-   Allow variable values with spaces. #6
-   Add `Python 3.11` support.

## [v3](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v3) - 2022-10-18
-   Fix deprecated `::set-output`.
-   Add `CodeQL` analysis workflow.

## [v2](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v2) - 2022-03-10
-   Simplified implementation setting matrix output from the python script.

## [v1](https://github.com/fabiocaccamo/create-matrix-action/releases/tag/v1) - 2022-03-07
-   Released action on GitHub Marketplace.
